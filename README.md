# Hundred Engine Homebrew tap

Mac apps by Hundred Engine.

```sh
brew install --cask hundredengine/tap/macarum
```

`brew upgrade` installs new versions.

| Cask | App |
|---|---|
| `macarum` | [Macarum](https://hundredengine.id/work/macarum/): clipboard history, memory check and file converter in the menu bar |
